# مرجع القواعد الإنجليزية الشامل — ٥ جمل ثابتة

الفكرة: **٥ جمل أساسية** بتتكرر في كل زمن ومع كل قاعدة، وكل جملة بتظهر بـ **٣ صيغ**: مثبتة / منفية / سؤال، مع الترجمة بالمصري تحت كل جملة.

## الجمل الخمس الأساسية (بصيغة المضارع البسيط كمرجع)

| # | English | بالمصري |
|---|---------|---------|
| 1 | The manager writes the report. | المدير بيكتب التقرير. |
| 2 | The company signs the contract. | الشركة بتوقع العقد. |
| 3 | She sends the invoice. | هي بتبعت الفاتورة. |
| 4 | The team delivers the car. | الفريق بيسلم العربية. |
| 5 | The client pays the bill. | العميل بيدفع الحساب. |

## الجزء الثالث: جمل الشرط (Conditionals / IF)

نفس الـ ٥ جمل، كل واحدة بقت "جملة شرط"، والنتيجة ثابتة: **the deal moves forward / الصفقة بتتنفذ**.

### 1. Type 0 — Zero Conditional (حقيقة عامة)

**التركيب / Formula:** If + present simple, present simple

| الجملة | English (مثبتة) | بالمصري |
|---|---|---|
| 1 | If the manager writes the report, the deal moves forward. | لو المدير بيكتب التقرير، الصفقة بتتنفذ. |
| 2 | If the company signs the contract, the deal moves forward. | لو الشركة بتوقع العقد، الصفقة بتتنفذ. |
| 3 | If she sends the invoice, the deal moves forward. | لو هي بتبعت الفاتورة، الصفقة بتتنفذ. |
| 4 | If the team delivers the car, the deal moves forward. | لو الفريق بيسلم العربية، الصفقة بتتنفذ. |
| 5 | If the client pays the bill, the deal moves forward. | لو العميل بيدفع الحساب، الصفقة بتتنفذ. |

- **منفية / Negative (مثال):** If the manager doesn't write the report, the deal doesn't move forward. — لو المدير مش بيكتب التقرير، الصفقة مش بتتنفذ.
- **سؤال / Question (مثال):** If the manager writes the report, does the deal move forward? — لو المدير كتب التقرير، الصفقة بتتنفذ؟

### 2. Type 1 — First Conditional (احتمال حقيقي في المستقبل)

**التركيب / Formula:** If + present simple, will + verb

| الجملة | English (مثبتة) | بالمصري |
|---|---|---|
| 1 | If the manager writes the report, the deal will move forward. | لو المدير كتب التقرير، الصفقة هتتنفذ. |
| 2 | If the company signs the contract, the deal will move forward. | لو الشركة وقعت العقد، الصفقة هتتنفذ. |
| 3 | If she sends the invoice, the deal will move forward. | لو هي بعتت الفاتورة، الصفقة هتتنفذ. |
| 4 | If the team delivers the car, the deal will move forward. | لو الفريق سلم العربية، الصفقة هتتنفذ. |
| 5 | If the client pays the bill, the deal will move forward. | لو العميل دفع الحساب، الصفقة هتتنفذ. |

- **منفية / Negative (مثال):** If the manager doesn't write the report, the deal won't move forward. — لو المدير ما كتبش التقرير، الصفقة مش هتتنفذ.
- **سؤال / Question (مثال):** If the manager writes the report, will the deal move forward? — لو المدير كتب التقرير، الصفقة هتتنفذ؟

### 3. Type 2 — Second Conditional (خيالي / غير حقيقي في الحاضر)

| 5 | If the client paid the bill, the deal would move forward. | لو العميل كان بيدفع الحساب، الصفقة كانت هتتنفذ. |

- **منفية / Negative (مثال):** If the manager didn't write the report, the deal wouldn't move forward. — لو المدير ما كانش بيكتب التقرير، الصفقة مكانتش هتتنفذ.
- **سؤال / Question (مثال):** If the manager wrote the report, would the deal move forward? — لو المدير كان بيكتب التقرير، الصفقة كانت هتتنفذ؟

## ملاحظة عن باقي قواعد الإنجليزي

"كل قواعد الإنجليزي" موضوع مفتوح جداً وميقدرش يتغطى بالكامل في ملف واحد. اللي فوق ده يغطي أهم حاجتين طلبتهم بالاسم (الأزمنة الـ ١٢ + المبني للمجهول) بالإضافة لجمل الشرط (IF). لو عايز أكمل بنفس الأسلوب (٥ جمل × ٣ صيغ) على قواعد تانية زي:

- **Modals** (can / must / should / have to)
- **Reported Speech** (الكلام المنقول)
- **Relative Clauses** (who / which / that)
- **Comparatives & Superlatives**
- **Question Tags**

قولّي أنهي قاعدة تحب تبدأ بيها وهعملها بنفس الترتيب.
