Conversation Questions
 Q1 How would you approach designing a scalable system
 A I'd start by identifying potential bottlenecks, then design for horizontal scaling and add redundancy where it matters most.

 Q2 What's the trade-off between microservices and a monolith
 A Microservices offer more flexibility and independent scaling, but they add complexity in communication and deployment compared to a monolith.

 Q3 How do you deal with technical debt in a project
 A I prioritize the debt that slows the team down most, and I refactor it gradually alongside new feature work.

 Q4 How would you investigate a sudden spike in latency
 A I'd check the monitoring dashboards first, look for a recent deployment or traffic spike, and trace the request to find the root cause.

 Q5 What does fault tolerance mean in a distributed system
 A It means the system keeps working correctly even if one component fails, usually through redundancy and graceful failure handling.
