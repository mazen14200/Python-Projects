Conversation Questions

1. How would you approach designing a scalable system?
I'd start by identifying potential bottlenecks, then design for horizontal scaling and add redundancy where it matters most.
2. What's the trade-off between microservices and a monolith?
Microservices offer more flexibility and independent scaling, but they add complexity in communication and deployment compared to a monolith.
3. How do you deal with technical debt in a project?
I prioritize the debt that slows the team down most, and I refactor it gradually alongside new feature work.
4. How would you investigate a sudden spike in latency?
I'd check the monitoring dashboards first, look for a recent deployment or traffic spike, and trace the request to find the root cause.
5. What does fault tolerance mean in a distributed system?
It means the system keeps working correctly even if one component fails, usually through redundancy and graceful failure handling.
