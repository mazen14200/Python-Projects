## 🔁 Make vs Do

### 🧠 القاعدة الأساسية
- **Do** → بنستخدمها مع الأنشطة والشغل العام (مفيش حاجة بتتصنع من الصفر): do homework, do a job
- **Make** → بنستخدمها لما بننشئ حاجة جديدة، أو نتكلم عن قرارات / مشاعر / علاقات: make a cake, make a decision

### Do + ...
| Expression | المعنى بالمصري |
|---|---|
| do homework | يعمل الواجب |
| do a favor | يعمل معروف |
| do business | يشتغل / يعمل تجارة |
| do the dishes | يغسل المواعين |
| do the laundry | يغسل الهدوم |
| do your best | يعمل اللي في إيده |
| do exercise | يعمل رياضة |
| do research | يعمل بحث |
| do a job | يعمل شغلانة |
| do damage | يخرب / يعمل ضرر |
| do the shopping | يعمل التسوق |
| do well / badly | ينجح / يفشل |

### Make + ...
| Expression | المعنى بالمصري |
|---|---|
| make a decision | ياخد قرار |
| make a mistake | يعمل غلطة |
| make money | يكسب فلوس |
| make a plan | يعمل خطة |
| make an effort | يتعب نفسه / يبذل مجهود |
| make a call | يرن على حد / يتصل |
| make friends | يعمل صحاب |
| make progress | يتقدم |
| make noise | يعمل دوشة |
| make a promise | يوعد حد |
| make an excuse | يلاقي عذر |
| make sense | يبقى له معنى |
| make a difference | يعمل فرق |
| make a mess | يعمل فوضى |
