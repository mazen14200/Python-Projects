# English Workplace Speaking — Interview, Teamwork, Software Development, Customer Service & Client Calls

> الهدف: تتعلم تختار الـ Tense حسب **المعنى والموقف**، مش تحفظ جمل وخلاص.
>
> المفتاح:
> - **Simple** = عادة / حقيقة / مسؤولية / Behavior ثابت.
> - **Continuous** = حاجة بتحصل دلوقتي أو الفترة الحالية.
> - **Perfect** = حاجة حصلت ولسه مرتبطة بالحاضر، أو إنجاز مهم دلوقتي.
> - **Perfect Continuous** = حاجة بدأت قبل دلوقتي ولسه مستمرة، والتركيز على المدة.
> - **Past Simple** = حاجة حصلت وانتهت في الماضي.
> - **Past Continuous** = حاجة كانت شغالة وقت حدث ماضي.
> - **Past Perfect** = حاجة حصلت قبل حاجة ماضية تانية.
> - **Will** = قرار / وعد / توقع.
> - **Going to** = خطة موجودة بالفعل.
> - **Present Continuous for future** = موعد أو ترتيب مؤكد.
> - **Could / Would** = طلب مهذب.
> - **Should** = نصيحة أو اقتراح.
> - **If** = شرط أو احتمال.

# FINAL RULE

لما تتكلم، متسألش نفسك أولًا:

> "أنهي Tense؟"

اسأل:

### أنا بوصف إيه؟

**عادة/حقيقة؟**
→ Simple.

**بيحصل دلوقتي؟**
→ Continuous.

**حصل ولسه مهم؟**
→ Perfect.

**بقاله مدة؟**
→ Perfect Continuous.

**حصل وانتهى في وقت محدد؟**
→ Past Simple.

**كان شغال وقتها؟**
→ Past Continuous.

**حصل قبل حدث ماضي؟**
→ Past Perfect.

**خطة؟**
→ Going to.

**قرار/وعد؟**
→ Will.

**شرط؟**
→ If.

**طلب مهذب؟**
→ Could / Would.

**نصيحة؟**
→ Should.

**قدرة؟**
→ Can / Could.

**ضرورة؟**
→ Must / Have to.

ده المفتاح اللي يخليك تتكلم في Interview وStand-up وMeeting وCustomer Service وClient Call بشكل طبيعي.
