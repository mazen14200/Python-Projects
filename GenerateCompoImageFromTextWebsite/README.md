# طريقة التشغيل

## 1) تثبيت المكتبات المطلوبة (مرة واحدة فقط)
```bash
pip install -r requirements.txt --break-system-packages
```

## 2) التشغيل عن طريق الواجهة الرسومية (الأسهل)
```bash
python app.py
```
هيطلعلك في الشاشة:
```
افتح المتصفح على: http://127.0.0.1:5000
```
افتح الرابط ده في أي متصفح، اكتب الكلمات في المربع بأي شكل تحبه
(بفواصل، بمسافات، بعلامات تنصيص أو من غيرها)، واضغط "أنشئ الصورتين".
هتشوف progress bar وسجل بالخطوات لحظيًا، وفي الآخر هيظهرلك "Done — تم
بنجاح" مع اسم الصورتين وصورة مصغّرة لكل واحدة، أو أي خطأ حصل لو العملية
فشلت.

**ملحوظة:** سيب نافذة الـ terminal اللي فيها `python app.py` شغالة
طول ما بتستخدم الصفحة. لو قفلتها، الصفحة مش هتقدر تشتغل.

## 3) أو التشغيل المباشر من الـ command line (اختياري)
لو تفضّل تشتغل بالطريقة القديمة من غير واجهة:
```bash
python surreal_compose.py {"desk","cat","car"}
```

## الناتج
- صورتين لكل تشغيل، بنفس الاسم + توقيت التشغيل:
  - الأساسية: `'desk', 'cat', 'car'_20260916_232733.png`
  - المُعلَّمة (بأسماء العناصر): `'desk', 'cat', 'car'_20260916_232733_labeled.png`
- الصورتين بيتحفظوا في نفس المجلد اللي فيه `app.py` و `surreal_compose.py`.
- الصور المؤقتة بتتحذف تلقائيًا بعد كل تشغيل.

## هيكل الملفات
```
app.py                  # سيرفر الواجهة (Flask) + الصفحة كاملة (HTML/CSS/JS) جواه
surreal_compose.py      # السكريبت الأساسي اللي بيعمل البحث والتركيب
requirements.txt
```

## ملاحظات
- أول مرة تشغّل، مكتبة `rembg` هتحمّل موديل AI صغير لإزالة الخلفية (مرة
  واحدة بس، وبعدها هيشتغل من غير إنترنت لهذه الخطوة تحديدًا).
- خطوة البحث عن الصور وتنزيلها بتحتاج اتصال بالإنترنت في كل تشغيل.
- لو كلمة معينة مالقاش لها صورة مناسبة، السكريبت بيتجاهلها ويكمل بالباقي
  (هتشوف تحذير أصفر/أحمر في سجل الصفحة، لكن العملية بتكمل عادي).
