# طريقة التشغيل

## 1) تثبيت المكتبات المطلوبة (مرة واحدة فقط)
```bash
pip install -r requirements.txt --break-system-packages
```

## 2) التشغيل
```bash
python surreal_compose.py '{"desk","cat","car"}'
```

- عدد الكلمات مرن: ممكن كلمتين وممكن عشرة أو أكتر.
- تأكد إن الأقواس والفواصل مطابقة تمامًا لصيغة الـ set في بايثون: `{"word1","word2","word3"}`

## 3) الناتج
- صورة واحدة باسم `final_composition.png` (مقاس 1024x1024) في نفس مجلد التشغيل.
- الصور المؤقتة (المُنزّلة + بعد إزالة الخلفية) بتتحذف تلقائيًا بعد الانتهاء.

## ملاحظات
- أول مرة تشغّل السكريبت، مكتبة `rembg` هتحمّل موديل AI صغير لإزالة الخلفية (مرة واحدة بس، وبعدها هيشتغل من غير إنترنت لهذه الخطوة تحديدًا).
- خطوة البحث عن الصور وتنزيلها بتحتاج اتصال بالإنترنت في كل تشغيل.
- لو كلمة معينة مالقاش لها صورة مناسبة، السكريبت بيتجاهلها ويكمل بالباقي (مع طباعة تحذير في الشاشة).
